# Dietrix Frontend

Клиентская часть системы подбора и ранжирования рецептов по медицинским диетам.

## Стек

- React 19 + JavaScript
- React Router 7
- CSS (без препроцессоров)
- Vite 7

## Установка и запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Сборка для продакшена

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
├── components/     UI-компоненты (карточки, формы, таблицы, уведомления)
├── data/           Справочные данные: диеты, продукты, рецепты, API-слой
├── hooks/          Глобальное состояние приложения (контекст + хранилище)
├── layouts/        Обёртки страниц (основной шелл, экран авторизации)
├── pages/          Страницы маршрутов
├── router/         Конфигурация маршрутов и защита авторизованных страниц
├── styles/         CSS: переменные, базовые стили, компоненты, страницы
└── utils/          Вспомогательные функции, константы, алгоритм скоринга
```

## Режимы работы

**Гостевой** — выбор одной из пяти диет (D1–D5), просмотр ленты рецептов и карточек без персонализации.

**Авторизованный** — регистрация с обязательным выбором диеты, настройка профиля (исключённые продукты, медицинские ограничения, дневные цели, предпочтения), получение персональных рекомендаций с оценкой и детализацией.

## Основные экраны

- **Выбор диеты** — пять карточек с описанием ограничений
- **Лента рецептов** — список рецептов с поиском и сортировкой
- **Карточка рецепта** — состав, нутриенты на 100 г, инструкция
- **Авторизация** — вход и регистрация
- **Профиль** — настройка ограничений и целей
- **Рекомендации** — персональная подборка с оценкой и фильтрами
- **Персональная карточка** — детализация оценки и причины подбора

Обработаны состояния пустой выдачи, загрузки и ошибок.
