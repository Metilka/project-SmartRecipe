# Руководство пользователя DIETRIX

## 1. Назначение приложения

DIETRIX — приложение для подбора рецептов под медицинские диеты и персональные ограничения пользователя.

Система помогает:

- выбрать подходящую медицинскую диету;
- просматривать рецепты, связанные с выбранной диетой;
- настроить личный профиль питания;
- получать персональные рекомендации с оценкой соответствия;
- добавлять рецепты в дневной план и считать нутриенты за день.

Рекомендации в приложении носят справочный характер и не заменяют консультацию врача или диетолога.

## 2. Запуск приложения

1. Откройте установочный файл `Dietrix Setup 1.0.0.exe`.
2. Если установщик попросит выбрать папку установки, укажите удобное место для программы.
3. Если установщик попросит выбрать папку для данных, выберите папку, где приложение сможет хранить локальную базу и служебные файлы.
4. Дождитесь окончания установки.
5. Запустите приложение через ярлык `Dietrix` или через файл `Dietrix.exe` в папке установки.

При первом запуске приложение может открываться дольше обычного: оно подготавливает локальную базу данных и запускает внутренний сервер.

## 3. Главное меню

В верхней части приложения находится главное меню DIETRIX.

Основные элементы:

- `Диеты` — выбор диеты для гостевого режима;
- `Лента` — список рецептов по выбранной диете;
- `Профиль` — настройки персонального профиля;
- `Рекомендации` — персональная подборка рецептов;
- `План` — дневной план питания;
- `Гость` — переход в гостевой режим;
- `Персонально` — переход к входу или персональному режиму;
- `Вход / регистрация` — открывает форму авторизации;
- `Выйти` — завершает персональную сессию и возвращает в гостевой режим.

Если пользователь не вошёл в аккаунт, доступны гостевые разделы. После входа становятся доступны профиль, рекомендации и дневной план.

## 4. Гостевой режим

Гостевой режим позволяет пользоваться приложением без регистрации.

### Выбор диеты

1. Откройте раздел `Диеты`.
2. Выберите нужную диету из списка.
3. После выбора приложение откроет ленту рецептов для этой диеты.

В гостевом режиме рецепты показываются без учёта личных исключений, любимых продуктов и медицинских флагов пользователя.

### Лента рецептов

В разделе `Лента` отображаются рецепты выбранной диеты.

Доступные действия:

- поиск по названию или описанию;
- фильтрация по методу приготовления;
- сортировка по названию, калорийности, белку или времени приготовления;
- открытие подробной карточки рецепта кнопкой `Подробнее`.

### Карточка рецепта в гостевом режиме

В карточке рецепта отображаются:

- название и описание;
- метод приготовления;
- время приготовления;
- количество порций;
- нутриенты на 100 г;
- ингредиенты;
- шаги приготовления.

Кнопка `Назад` возвращает к предыдущему экрану.

## 5. Регистрация и вход

Чтобы получать персональные рекомендации, нужен аккаунт.

### Регистрация

1. Нажмите `Вход / регистрация` или `Персонально`.
2. Переключитесь на вкладку `Регистрация`.
3. Введите email.
4. Введите пароль длиной не менее 8 символов.
5. Нажмите `Зарегистрироваться`.
6. После успешной регистрации приложение предложит войти в аккаунт.

Если вы передумали регистрироваться, нажмите `Вернуться в гостевой режим`.

### Вход

1. Откройте вкладку `Вход`.
2. Введите email и пароль.
3. Нажмите `Войти`.
4. После успешного входа приложение откроет раздел `Профиль`.

### Выход из аккаунта

Нажмите `Выйти` в верхнем меню. Приложение завершит персональную сессию и вернётся в гостевой режим.

## 6. Профиль пользователя

Раздел `Профиль` нужен для настройки персональной выдачи рецептов.

### Выбор текущей диеты

В блоке `Текущая диета` выберите диету из списка.

Смена диеты влияет на:

- список разрешённых продуктов;
- набор рецептов в персональных рекомендациях;
- расчёт оценки рецептов;
- предупреждения в дневном плане.

### Исключённые продукты

В блоке `Исключённые продукты` отметьте продукты, которые нужно убрать из рекомендаций.

Рецепты с выбранными исключёнными продуктами не попадут в персональную выдачу.

### Любимые продукты

В блоке `Любимые продукты` отметьте продукты, которые вы предпочитаете.

Рецепты с такими продуктами получают преимущество при ранжировании.

Один и тот же продукт не может быть одновременно любимым и исключённым.

### Медицинские ограничения

Доступные переключатели:

- `Низкий натрий`;
- `Низкий сахар`;
- `Низкий жир`;
- `Без острого`;
- `Без кислого`;
- `Без насыщенных жиров`.

Эти параметры ужесточают фильтрацию и могут исключать неподходящие рецепты из персональной выдачи.

### Дневные цели

В блоке `Дневные цели` можно указать целевые значения:

- ккал в сутки;
- белки в сутки;
- жиры в сутки;
- углеводы в сутки;
- сахар в сутки;
- натрий в сутки.

Если поле оставить пустым, приложение использует ориентиры выбранной диеты.

### Сохранение профиля

Доступные кнопки:

- `Сохранить` — сохраняет изменения профиля;
- `Сбросить изменения` — возвращает актуальные данные с сервера;
- `Сохранить и обновить рекомендации` — сохраняет профиль и открывает обновлённую персональную выдачу.

## 7. Персональные рекомендации

Раздел `Рекомендации` доступен после входа в аккаунт и выбора диеты.

Приложение формирует список рецептов с учётом:

- выбранной диеты;
- исключённых продуктов;
- любимых продуктов;
- медицинских ограничений;
- дневных целей по нутриентам;
- способа приготовления;
- состава рецепта.

### Оценка рецепта

Каждый рецепт получает итоговую оценку. Чем выше оценка, тем лучше рецепт подходит текущему профилю.

В карточке рекомендации отображаются:

- название и описание;
- итоговая оценка;
- метод приготовления;
- сахар;
- натрий;
- краткое объяснение, почему рецепт подходит;
- кнопка `Открыть`;
- кнопка `+ В план`.

### Фильтры рекомендаций

Вверху раздела доступны:

- поиск по названию или описанию;
- минимальная оценка;
- фильтр по методу приготовления.

Если рецептов нет, попробуйте снизить минимальную оценку, изменить метод приготовления или ослабить ограничения в профиле.

## 8. Персональная карточка рецепта

Карточка открывается из раздела `Рекомендации`.

На странице отображаются:

- название рецепта;
- итоговая оценка;
- выбранная диета;
- метод приготовления;
- время приготовления;
- количество порций;
- детализация оценки;
- причины, почему рецепт подходит;
- причины штрафов или ограничений;
- нутриенты на 100 г;
- ингредиенты;
- шаги приготовления.

### Детализация оценки

Оценка разбивается на несколько частей:

- `Состав` — насколько ингредиенты подходят правилам диеты;
- `Нутриенты` — насколько нутриенты соответствуют целям;
- `Способ приготовления` — насколько метод приготовления подходит диете;
- `Персональные предпочтения` — совпадение с любимыми продуктами и предпочтениями.

### Добавление в дневной план

1. Укажите количество порций в поле `Порций`.
2. Нажмите `+ В план`.
3. После добавления появится уведомление.

Количество порций можно задавать с шагом 0.5.

## 9. Дневной план

Раздел `План` показывает рецепты, добавленные на текущий день.

В дневном плане отображаются:

- суммарные ккал;
- белки;
- жиры;
- углеводы;
- сахар;
- натрий;
- список добавленных рецептов;
- количество порций;
- нутриенты по каждому рецепту;
- предупреждения о превышении норм.

### Очистка плана

Нажмите `Очистить план`, чтобы удалить все рецепты из дневного плана.

Дневной план хранится для текущего дня. При перезапуске backend-сервера или смене даты он может быть очищен.

## 10. Частые ситуации и ошибки

### Не открывается приложение

Подождите 1-2 минуты после первого запуска. Desktop-версия поднимает локальную базу данных и сервер.

Если окно не появляется:

- закройте приложение через диспетчер задач;
- запустите его снова;
- проверьте, что антивирус не заблокировал локальный запуск.

### Не удалось получить список диет

Обычно это означает, что backend или база данных не запущены.

Перезапустите приложение.

### Не получается зарегистрироваться

Проверьте:

- email должен быть в корректном формате;
- пароль должен содержать минимум 8 символов;
- пользователь с таким email не должен уже существовать.

### После регистрации приложение просит войти

Это нормальное поведение. После регистрации откройте вкладку `Вход` и войдите с тем же email и паролем.

### Нет персональных рекомендаций

Возможные причины:

- не выбрана диета в профиле;
- слишком много исключённых продуктов;
- включены слишком строгие медицинские ограничения;
- установлена слишком высокая минимальная оценка;
- выбран метод приготовления, по которому нет рецептов.

Попробуйте изменить профиль и нажать `Сохранить и обновить рекомендации`.

### Рецепт исключён фильтрацией

Например:

- содержит исключённый продукт;
- содержит запрещённый для диеты продукт;
- использует неподходящий метод приготовления;
- превышает лимит по сахару, жирам или натрию;
- содержит кислые, острые продукты или насыщенные жиры при включённых ограничениях.

### Появились предупреждения в дневном плане

Предупреждения означают, что суммарные нутриенты выбранных рецептов могут превышать нормы диеты или личные дневные цели.

Проверьте количество порций или замените часть рецептов.

## 11. Рекомендации по работе

- Сначала выберите диету в гостевом режиме и посмотрите общий каталог рецептов.
- Затем зарегистрируйтесь, чтобы настроить персональные ограничения.
- Не отмечайте слишком много исключённых продуктов одновременно: выдача может стать пустой.
- После изменения профиля используйте `Сохранить и обновить рекомендации`.
- Перед добавлением рецепта в план откройте его карточку и проверьте причины оценки.
- Используйте дневной план как ориентир, а не как медицинское назначение.
